# BrightStar Editor — Hoàng Đức

Công cụ ghép ảnh + video thành 1 file dài, xuất 4K, tận dụng GPU khi render.

## Cài đặt
Tải file `BrightStarEditor_v<phiên bản>.zip` ở mục [Releases](https://github.com/tyml0ve12/brightstar-editor/releases/latest), giải nén, bấm đúp `CAI DAT.bat`.

App tự kiểm tra và cập nhật bản mới mỗi khi mở.
